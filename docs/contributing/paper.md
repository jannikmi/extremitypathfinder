# JOSS paper

The paper for the [Journal of Open Source Software](https://joss.theoj.org) (JOSS) is in `paper/` (#190).
It is not part of the package or its documentation: `check-manifest` ignores `paper/*`.
The plan and the open tasks of the submission are in the pull request that added the paper (#196).

## Files

- `paper/paper.md`: the paper. `paper/paper.bib`: its references.
- `paper/references/`: one note per known use of the package, with the statuses and how to repeat the search
  (`paper/references/README.md`). `findings.md` summarises what the known uses mean for the package.
- `paper/*.svg`: the figures, generated by `scripts/paper_figures.py` (cf. [Figures](#figures)).

## Content

- **Sections and length** as JOSS requires them ([paper format](https://joss.readthedocs.io/en/latest/paper.html)):
  Summary, Statement of need, State of the field, Software design, Research impact statement,
  AI usage disclosure, Acknowledgements, References. 750 to 1750 words, counted without the front matter and
  HTML comments, figure captions included. Cut text before adding any.
- **No API documentation**: refer to the documentation instead. The paper makes no claim that the API stays
  unchanged, because the published paper is frozen while the API evolves.
- **Evidence of use**: only references with the status "Direct use" in `paper/references/` count.
- **Every statement is checked by the maintainer** before submission, in particular text drafted by an AI tool
  and the AI usage disclosure (cf. [AI-assisted contributions](ai-assisted-contributions.md)).
- **Benchmark-derived numbers**: the speed-ups, graph sizes and invalid paths in the text and the captions come from
  the committed benchmark results. Update them, and the figures, after every full run
  (cf. [After a full run](performance.md#after-a-full-run)).

## Figures

The figures reuse the drawings of the documentation (`scripts/docs_figures.py`) and of the benchmark
(`benchmarks/plot.py`), with the committed results. Regenerate them when these drawings or the results change:

```sh
uv run --all-extras --group benchmark python scripts/paper_figures.py
```

- **SVG**: the PDF build of JOSS converts SVG to vector graphics (`rsvg-convert`), and GitHub shows them in the
  preview of `paper.md`. PNG is only needed for raster images.
- Sized for the text width of the PDF (about 7 inch), with a white background.
- Deterministic like the figures of the documentation (cf. [Documentation](documentation.md#content)).
- Referenced with a label, e.g. `![Caption.\label{fig:name}](name.svg)` and `\autoref{fig:name}` in the text.
  Figures are numbered in the order they appear.

## Building the PDF

With the Docker image of the JOSS build, from the repository root:

```sh
docker run --rm -v "$PWD/paper":/data -e JOURNAL=joss openjournals/inara -o pdf /data/paper.md
```

It writes `paper/paper.pdf` (do not commit it). The build must pass without LaTeX warnings.
Look at every page with a figure: a figure is placed where it fits, not always next to its reference.
